
# SkillSync – Skill Sharing & Mentorship Platform

SkillSync is a platform that connects learners with mentors to learn new skills through AI-powered roadmaps, skill matching, and mentoring sessions.

## Features

- Skill Matching
- AI-Powered Learning Roadmaps
- Mentorship Session Booking
- Mentor Approval
- In-App Chat
- Google Meet Integration

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Socket.IO
- Google Gemini AI

## How to Use
1. Open the live demo link.
2. Sign in using the test credentials.
3. Explore mentors and skill matches.
4. Generate an AI learning roadmap.
5. Request mentoring sessions and explore the platform.

## Project Goal
To make learning easier by connecting learners with mentors and providing personalized skill development.
